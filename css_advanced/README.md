# CSS Advanced - SmileSchool

Welcome to the **CSS Advanced** project! This repository contains the complete styling implementation for the SmileSchool webpage based on the Figma design specifications.

---

## 📐 Project Overview

The objective of this project is to take the semantic HTML5 layout developed in `html_advanced` and apply pure CSS styling, layout structures, typography, and visual assets to match the target design accurately.

### 🎯 Key Highlights

- **Header & Banner**: Styled hero section with custom background image, logo positioning, white navigation links, hero heading, call-to-action button, and instructor avatars.
- **Quotes**: Testimonial section with circular author avatar, stylized blockquote text, and responsive layout.
- **Popular Videos**: Grid layout featuring video preview cards, play icons, custom purple accents, instructor thumbnails, and star ratings.
- **Free Membership**: Features section highlighting key perks with purple icons, centered headings, and a registration button.
- **FAQ Grid**: Clean 2x2 grid structure presenting common questions and answers.
- **Footer**: Centered container with logo, social media links, and copyright statement.
