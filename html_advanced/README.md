# HTML Advanced

Welcome to the HTML Advanced project! This repository contains the semantic HTML structure for a modern webpage, built from scratch based on a designer's mockup provided on Figma.

---

## Project Overview

The objective of this project is to implement pure, semantic HTML5 without any styling, CSS, or JavaScript. The focus is solely on building a well-structured, accessible, and standards-compliant document hierarchy.

### Key Objectives

- Use semantic HTML5 elements (<header>, <nav>, <main>, <section>, <article>, <aside>, <footer>, etc.).
- Establish clear document outline and heading hierarchy (<h1> through <h6>).
- Ensure full accessibility and web standards compliance.
- Build a solid foundation for future CSS styling and responsiveness.
